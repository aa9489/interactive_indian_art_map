# Interactive Art Map of India

A responsive college project exploring 10 regional Indian art traditions.

## Run
Open `index.html` in a browser with an internet connection.

## Map
The page uses Leaflet + OpenStreetMap and loads a simplified India state/UT GeoJSON boundary layer from a public GitHub-hosted dataset. The state layer provides the geographic outline; art markers provide the regional art-form interaction.
